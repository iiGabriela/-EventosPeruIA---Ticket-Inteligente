Resumen ejecutivo

  • Fallo crítico cerrado: la API ahora identifica cada cuenta por el UID de Firebase (usuario.firebase_uid). Un perfil sin UID solo se vincula a un correo verificado. Se confirmó que admin@eventia.pe existía en Supabase sin cuenta en Firebase: el riesgo era real.
  • Fallo alto cerrado: el atajo X-User-Email está apagado por defecto y solo se activa a propósito en Development.
  • Arranque sin configuración: el frontend trae su .env; el backend solo necesita la cadena de conexión en user-secrets. La clave del QR se genera sola en Development.
  • IA sin Ollama: chat, embeddings y reglas de moderación funcionan con Gemini y una API key. Sin clave la API arranca igual.
  • HU completadas: reglas automáticas de moderación (antes se guardaban pero nunca se evaluaban, ni las simples ni las de IA), memoria de conversación del chat, reseñas solo con check-in, validación SUNAT/municipal.
  • Verificado: 38 pruebas del backend y 12 del frontend pasan; la API se probó en ejecución contra Supabase (rutas públicas, 401 sin sesión, roles, exportación) y el frontend carga la cartelera y la pantalla de acceso.
  • No verificado: el chat y las reglas de IA con el modelo real (falta la API key de Gemini) y el recorrido con sesión iniciada (compra → QR → check-in → reseña), porque requiere una contraseña.
Suposiciones. (1) Las HU y sus criterios salen del documento de Google Docs del equipo (US-01 a US-17). (2) El repositorio de iiGabriela es el backend; el de ANIM-OS, el frontend. (3) Los criterios de interfaz se contrastaron buscando cada elemento en el código del frontend, no navegando cada pantalla con sesión iniciada.

Qué falta para el 100%

Imprescindible para entregar

  • Crear la API key de Gemini en Google AI Studio, guardarla con dotnet user-secrets y probar el chat y una regla de moderación con IA.
  • Recorrer con sesión iniciada: compra → QR → check-in → reseña → notificación → moderación.
  • Cuentas de la demo: registrar cuentas nuevas desde el frontend y dar el rol de administrador con el INSERT de Seguridad_FirebaseUid.sql, o enlazar a mano los perfiles @eventia.pe.
  • Revisar y fusionar las dos ramas; cada integrante debe configurar su cadena de conexión.

Recomendable

  • Calibrar AI:MinScore (0.5) con preguntas reales.
  • Cambiar la contraseña de base que quedó en el historial de git, si se usa fuera de local.
  • Desplegar API y frontend; añadir el dominio a Cors:Origenes y a Firebase.
  • Dividir src/App.vue con vue-router y un store.
